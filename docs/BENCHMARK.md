## How to read these numbers

- The scenarios are **curated by the rule author** (synthetic attacks, a synthetic normal day): the detection rate is a regression measure of the rules, not an estimate of real-world detection, and "0 false alerts" only covers the benign traffic that exists in `datasets/`.
- Every scenario is replayed like production does (normalizer, then the engine with **all** rules loaded). Benign scenarios must raise no alert from any rule; an attack must raise exactly the declared number of alerts, from the owning rule and from the rules it declares with `# also`.
- Detection *delay* is a property of the running system, not of these files: see the lab measurement in [`lab/README.md`](../lab/README.md). Engine throughput: `sentinel bench --throughput` (varies per machine, therefore not part of this file).
